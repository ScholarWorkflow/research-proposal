# 候选选题评分

两个以上候选、需要模型说明“为什么推荐这个”时，用同一组评分项逐项打分。只有一个候选，或用户已经明确决定时，不评分；直接按[写完到什么程度](research-design.md#写完到什么程度)检查方案。

这里评的是本稿的研究问题候选，不是上游教授方向的选择；教授方向只决定范围，不能拿这套分数替代 `discover` 的方向决定。

评分不是录取概率，也不把选题变成算术。总分只用于排序和暴露分歧，不是对选题价值的测量。它只做三件事：

1. 把“我觉得这个更好”拆成可以逐项检查的理由。
2. 暴露候选之间的分歧：总分接近时，差在哪几项。
3. 新证据进来时，知道该重打哪几项，而不是整表重来。

## 九项从哪来

这九项不是另起一套标准，都能回到本技能的规则：

| 评分项 | 出自 |
|---|---|
| 问题成形 | [写完到什么程度](research-design.md#写完到什么程度)第一项；同文件的“研究计划不是学习计划” |
| 价值 | 「写完到什么程度」里的“为什么值得弄清” |
| 新意落点 | [新颖性写在哪里](research-design.md#新颖性写在哪里) |
| 先行核对 | [有限补查](research-design.md#有限补查)的三项对应关系 |
| 空白成因 | [新颖性写在哪里](research-design.md#新颖性写在哪里)的危险信号 |
| 方法落地 | [写完到什么程度](research-design.md#写完到什么程度)第三项；[准备到哪一步算够](research-design.md#准备到哪一步算够)的三问 |
| 准备档位 | [准备到哪一步算够](research-design.md#准备到哪一步算够)的 A–E 档 |
| 两种结果 | [写完到什么程度](research-design.md#写完到什么程度)第四项 |
| 两个弱点 | [写完到什么程度](research-design.md#写完到什么程度)第五项 |

前五项判断方向能不能立，中间两项判断能不能做，后两项判断写出来够不够。这些判据用于排序，不替代[写完到什么程度](research-design.md#写完到什么程度)的最低要求；2 分比最低要求更严，1 分仍可能达标。

## 评分项与默认权重

每项 0、1、2 分。2 分表示按技能规则已经成立，1 分表示部分成立或证据不足，0 分表示不成立。

| 项 | 权重 | 2 分 | 1 分 | 0 分 |
|---|---|---|---|---|
| 问题成形 | 15 | 一句话说出对象、条件、要弄清什么，换个人能复述 | 有对象和问题，但条件或范围缺一项 | 只有兴趣或主题 |
| 价值 | 15 | 能说出谁会在什么判断或做法上因答案改变，带一个具体场景 | 只有研究者自己关心，或价值只写成“填补空白” | 答案是常识，或没人会因此改变判断或做法 |
| 新意落点 | 15 | 判定句套得出来，落点明确到问题、方法、对象或数据、解释中的一项，且有依据 | 能说清新在哪，但落点含糊或差别很窄 | 四项都没有变化 |
| 先行核对 | 10 | 最接近的工作读过全文，能逐篇说出对象、方法、结论和差别，差别有来源定位 | 只做过摘要或搜索级核对，标“待核” | 还没核对，或差别没有依据 |
| 空白成因 | 15 | 真空白：最接近的三篇在问题上就不同，不是同一问题换工具 | 同题换做法：同一问题已有人做，但方法、解释、对象或数据、基底或指标至少一项有可说明的变化；逐项判据见下 | 伪空白：最接近的工作已完整回答同一问题，本稿四项都没有可说明的变化；或找不到三篇最接近的工作 |
| 方法落地 | 15 | 数据或材料从哪来、要多少、用什么工具、按什么顺序、怎么判断，都答得出 | 有一项答不出，需要缩范围 | 只能说“用某种方法” |
| 准备档位 | 5 | A 或 B 档 | C 或 D 档 | E 档 |
| 两种结果 | 5 | 两个方向相反的结果都成立，各自有解释，都会改变结论或下一步 | 写了两个，各自有解释，但不是两个都改变结论或下一步 | 只写一种预期，或写了两个但其中一个没有解释 |
| 两个弱点 | 5 | 两个弱点都具体到会影响哪一步，各有可执行的应对或缩小办法 | 两个都有应对，但其中一个是“样本有限”这类通用话 | 没有弱点，或只有“我会努力”，或有一个没有应对或缩小办法 |

### 空白成因 1 分：按四位置逐项判断

同一问题已有人做，但至少一项有可说明的变化：

- **方法**：分析方法新，能说明新在哪里。不要求已经跑出新结论。
- **对象或数据**：能说出与已有对象或数据哪里相同、哪里不同。
- **解释**：能说明原读法在什么情况下会出错。
- **基底或指标**：能说明新基底或指标回答旧基底或指标答不了的什么；说不出，按 0。

方法、对象或数据、解释这三项，只要变化说得清，就给 1 分；基底或指标多一道“多回答了什么”的要求，因为换基底最容易把同一件事重做一遍。

**空白成因的硬要求**：打 2 或 1，必须附三篇最接近的工作、各自差在哪一步、差别属于问题还是工具。打 1 还要按上面四位置写清变化；用来支撑 1 分的那一项写不出，按 0 分。缺这三项也按 0 分。这条防止把“搜不到”当成“没人做”。

三篇是评分所需的最低证据，不改变「有限补查」不按固定篇数凑数的停止条件。

空白成因 0 有两种：查过之后判定伪空白（含换基底或指标但答不出新回答）、还没查够三篇。最后一种在报告里写“待补”，补够证据后重打；前一种按 0 记录理由。

“结论是常识”由「价值 = 0」的软门槛处理，不放进空白成因 0，避免把方法、对象或数据、解释新意硬停。

**准备档位不是及格线**：1 分包括 C 和 D，D 是多数人的现实位置，技能明确说可接受。不要因为这一项是 1 就把候选判死。

## 撞车类型怎么落到评分

撞车判断是诊断，不是第十个评分项；九项权重、两项硬门槛和九项的 0/1/2 判据都不变。
它只说明撞车判断落到哪一项，不重述也不收紧判据：

| 撞车判断 | 落到哪一项 | 怎么用既有判据 |
|---|---|---|
| 完全重复 | 空白成因 | 没有可说明的变化时按 0；其余按该项 0/1/2 判据 |
| 方法置换 | 空白成因、新意落点 | 按「方法」判据和「新意落点」判据，不另加条件 |
| 对象置换 | 空白成因、新意落点 | 按「对象或数据」判据和「新意落点」判据，不另加条件 |
| 同结论、不同路径 | 空白成因、新意落点 | 按「解释」判据和「新意落点」判据，不另加条件 |
| 结论一致 | 空白成因 | 按该项判据；新条件本身构成四位置之一的可说明变化时，按对应判据 |
| 结论矛盾 | 空白成因、价值 | 按两项各自判据；只澄清可界定分歧 |
| 评价空白 | 空白成因、新意落点 | 按「空白成因」判据；换评价轴仍按「换基底或指标」的更高门槛 |

判据仍以本文件前面的评分表和「空白成因 1 分」小节为准。「先行核对」仍要求三篇
最接近的工作；撞车诊断阶段读多少篇不设上限，但不替代评分的最低证据。撞车判断不
单独给分，也不能用信号数量代替「空白成因」的证据要求。

## 先过门槛，再算总分

两项硬门槛，任一项为 0，不进入排序，也不推荐：

| 硬门槛 | 为什么 |
|---|---|
| 新意落点 = 0 | 技能要求四项里至少一项有可说明的变化；四项全无时“不进入下一步”。 |
| 空白成因 = 0 | 伪空白、换基底或指标但答不出新回答，或还没查够三篇；最后一种标“待补”，补完再评。 |

七项软门槛，可以为 0，但不能直接推荐；先写清补法：

| 软门槛 | 补法 |
|---|---|
| 问题成形 = 0 | 先把兴趣收窄成一句话问题，再比较。 |
| 价值 = 0 | 先找使用者或改问题；找不到，按备选处理。 |
| 先行核对 = 0 | 补查三篇最接近的工作，并留下差别依据，再比较。 |
| 方法落地 = 0 | 先把数据、数量、工具、顺序、判断办法缩到能答。 |
| 准备档位 = 0 | 先按[准备到哪一步算够](research-design.md#准备到哪一步算够)抬到 D 档；抬不上来，按备选处理。 |
| 两种结果 = 0 | 先补出两个方向相反、各自有解释的结果，再比较。 |
| 两个弱点 = 0 | 先补出两个弱点及各自的应对或缩小办法，再比较。 |

硬门槛和软门槛的区分来自技能原文：新意四项全无时“不进入下一步”；空白成因 0 中，找不到三篇对应“没有相近先行研究是危险信号”，已有人做完或换基底/指标无新回答对应“把别人的工作重做一遍”。方法答不出时原文说“把方案缩到能答的细度，或者换一种能答的方法”，准备 E 档说“不够”，先行核对 0 是还没查或没留下依据，三者都可以补，所以不直接淘汰。

权重不能把硬门槛买过去。把某一项的权重调高，只能改变排序，不能把 0 分变成通过。分数也不能把 1 分判成停：某项得 1 分说明它部分成立，不等于全不成立。

## 判决与停因

打分只用于比较与排序，不用于决定去留。一个方向还能不能继续做，单独按本节判。判决词与分数分开记：分数按既有判据照实记，不为配合判决改写。

判决词只有五种，与保存的 `gate` 一一对应：

| 判决词 | `gate` | 含义 | 总分 |
|---|---|---|---|
| 可推进 | `pass` | 两条硬门槛都过，进入排序与推荐 | 照算 |
| 待补 | `pending` | 缺本节指定的证据，尚不能判 | 不给 |
| 备选 | `soft_stop` | 硬门槛过了，但有软门槛为 0，按补法处理 | 照算，写明不能直接推荐 |
| 并入 | `merge` | 作为一节并入另一个候选 | 不给独立总分 |
| 停 | `hard_stop` | 命中下方三类停因之一 | 不给 |

只有三类理由可以记「停」：

- `novelty_zero`：新意落点 = 0，四项都没有可说明的变化。
- `gap_zero`：空白成因 = 0，且已判定为伪空白（最接近的工作已完整回答同一问题，或换了基底或指标但答不出多回答了什么）。
- `problem_invalid`：问题不成立。它不在九项里，也不是第三个硬门槛；判定后单列停因，不并入前两种。

「待补」有两个触发条件。一是还没查够三篇：这是证据没到手，不是伪空白，补够后重打。二是推荐所依赖的关键项只有摘要级证据。「推荐所依赖的关键项」指推荐语第 2 句点名的领先项：推荐语要写明在哪几项领先、领先多少，点到的才算，没点到的项不算；点名多项时，任一项只有摘要级证据即记待补。

同一情形在「推荐怎么写」原先写作“补不了，就把这个领先项从推荐理由里去掉”，那条路仍保留总分与排序。按本节，领先项只有 `摘要：` 或 `推测：` 依据时整条候选记「待补」，不给总分、不排序，把领先项补成 2 分要求的依据、或换一个有全文依据的领先项后再重打。“先补成该项 2 分所要求的依据，再推荐”的方向不变。

`待补` 在汇总、比较和转述时不得改写为「停」，也不得因为另一个候选分数更高就把它写成「停」。

`problem_invalid` 用五个问句诊断，有一项成立就按它记停：

1. 两边是不是恒等：把准则、惩罚或统计量换写之后，与已有工作是不是同一个式子。
2. 同一份观测资料是不是对应两个相反结论：如果是，排序不可识别。
3. 参数是不是依赖不可观测的分布：只在不可观测的完整数据上定义的量，不进入可估范围。
4. 检验在真零假设下是不是必然拒绝、或必然不拒绝：恒真与恒假都没有经验内容。
5. 定义域是不是空的：目标量存在的条件在动机场景里是不是从不成立。

这一类只写 `stop_reason`，评分表按既有 0/1/2 判据照实记，不为了配合停因改写分数：按判据确实是 0 的（例如恒等式对上「四项都没有变化」）就记 0，是 1 就记 1；报告里单列停因。

以下东西不能单独判停：总分；价值、新意、空白三项的合计；任何一项的 1 分；预注册判据线与效果量线（例如偏相关 0.05、纯度 0.02、两个百分点、覆盖率 0.93）；作者自己写下的后续工作；单次实现或单个编码器得出的结果；方法置换或对象置换本身。判据线命中而两条硬门槛都过时，只能记负结果、边界题或备选。

**价值项自检**：把报告里写价值的原句套回 0 分定义。出现“答案不改变谁的做法”“只避免傻事”“只改报告措辞”“只填补空白”“只有研究者自己关心”这类说法时，记 0，不能记 1。

**负结果与边界题**。零结果与反向结果是可以写的形态，按下面一句套一遍：

> 先行研究认为 A 在 B 条件下成立；本稿实测在 B′ 条件下不成立或更差，因此 A 的适用范围是……，简单规则在……时已经够用。

套得出来就落在[新颖性写在哪里](research-design.md#新颖性写在哪里)的「解释」位置，记 1 分；它不是失败的计划。写法细则与证据进来之后的五类分流见[证据推翻方案之后](research-design.md#证据推翻方案之后)。

保存时，`gate` 之外按判决另写字段：`hard_stop` 写 `stop_reason`，`merge` 写 `merged_into`（被并入的候选 `id`）。

## 打分前先定证据

每一项的分数后面必须跟一句依据。依据开头写明来源：

- `全文：` 论文全文、方法或附录。
- `事实：` 用户材料、公开事实、实际数据或可核对场景。
- `摘要：` 只看到摘要、检索结果或二手总结，标“待核”。
- `推演：` 从已有事实或规则一步步推出，能写出推理链。
- `推测：` 还没有依据，只能标“待核”。

规则：

- 2 分要有 `全文：`、`事实：` 或 `推演：` 依据；只有 `摘要：` 或 `推测：` 时最高 1 分。
- 先行核对、空白成因、准备档位这三项，2 分必须是 `全文：` 或 `事实：`；`推演：` 不够。方法落地可以用 `推演：`，因为技能允许把步骤拆到能照着做而尚未动手（D 档）。
- 0 分也要写依据：哪篇工作已经做完，或哪条规则判定不成立。
- 同一轮评分使用同一个证据截止时间。
- 先行核对和空白成因放在同一轮补查之后打分，不能先打分再补文献。先打后补会把“还没查”记成“差别窄”，补完再改，总分就不可比。

## 怎么算总分

九项权重合计 100，默认如下：

| 项 | 权重 |
|---|---|
| 问题成形 | 15 |
| 价值 | 15 |
| 新意落点 | 15 |
| 先行核对 | 10 |
| 空白成因 | 15 |
| 方法落地 | 15 |
| 准备档位 | 5 |
| 两种结果 | 5 |
| 两个弱点 | 5 |
| 合计 | 100 |

```text
合计 = Σ(权重 × 分数) ÷ (2 × Σ权重) × 100
```

九项都是 2 分时合计 100，都是 1 分时合计 50。加入可选项后，Σ权重不再是 100，公式仍按实际权重合计计算。

权重是默认起点，不是标准答案。五项 15 分（问题、价值、新意、空白、方法）是决定方向能不能立、能不能做的部分；先行核对 10 分，因为它是新意和空白的证据，不单独决定方向好坏；准备档位、两种结果、两个弱点各 5 分，因为它们可以在选定方向后补，或者 D 档本身可接受。

## 怎么报给用户

1. 先列候选，每个候选一句话问题。
2. 给一张总分表，按判决五态标注：`pass` 的可推进候选进入排序；`pending` 写缺的指定证据，不给总分；`soft_stop` 的备选候选总分照算，并注明不能直接推荐；`hard_stop` 的候选写 `stop_reason`，不给总分；`merge` 的候选指向被并入的候选，不给独立总分。
3. 给每个候选一张评分依据表：项、权重、分、加权分、依据。加权分 = 权重 × 分 ÷ 2。九项权重合计 100 时，合计就是加权分之和；加入可选项后，合计 = 加权分之和 ÷ 实际权重合计 × 100。
4. 用一段话说明前两名差在哪几项、这个差距意味着什么取舍。不要只报总分。
5. 前两名只差一个评分项的一档，或总分差小于最小的评分项权重（默认 5 分）时，默认按“总分不足以单独决定”处理：把取舍摆出来，让用户按优先项选，或由模型明确说明采用了哪条优先项。

例如：

| 候选 | 问题 | 价值 | 新意 | 先行 | 空白 | 方法 | 准备 | 两结果 | 两弱点 | 合计 |
|---|---|---|---|---|---|---|---|---|---|---|
| 甲 | 2 | 2 | 2 | 1 | 1 | 2 | 2 | 2 | 2 | 87.5 |
| 乙 | 2 | 2 | 2 | 1 | 2 | 1 | 1 | 2 | 2 | 85.0 |

这两个候选的差别是“空白成因高一档”换“方法落地和准备档位各低一档”。2.5 分小于最小的评分项权重 5，所以这组分数不足以单独决定，要把取舍摆出来让用户选。

## 推荐怎么写

推荐语至少带三句：

1. 推荐哪个。
2. 它在哪几项领先，领先多少。
3. 它在哪几项落后或待核；如果用户更看重落后项，应该改选哪个。

推荐所依赖的关键项不能还是“待核”。如果领先项只有 `摘要：` 或 `推测：` 依据，先补成该项 2 分所要求的依据再推荐；补不了，按[判决与停因](#判决与停因)把这条候选记「待补」，不给总分、不排序，等补完全文或换一个有全文依据的领先项后重打。

例如：

> 推荐乙。乙在空白成因上领先一档（2 对 1），说明它的空白更可能是真空白；甲的总分高 2.5，靠的是方法落地和准备档位各领先一档（2 对 1），说明甲更容易马上开工。如果用户更看重两年内能做完，选甲；如果更看重问题本身值不值得填，选乙。

不要写“综合来看乙更均衡”。要说清“均衡”是哪几项换哪几项。

## 调整权重

用户改优先级时，只改权重，不改分数。

- 每次改权重后重新算总分，并在表头标“按用户权重”。
- 权重可以设为 0，表示这一项只展示、不计入；不能设为负数。
- 至少保留一项大于 0。
- 新增评分项要同时给出 0、1、2 的判据和权重；不能只加名字。
- 改后的总分不能和默认权重的总分放在同一张表里比较。

例子：用户说“我更看重两年内能做完”，把方法落地、准备档位的权重调高；用户说“我必须贴着教授的方向”，把下面“范围连接”的权重调到大于 0。调完要写明，不能悄悄改。

## 可加的一项：范围连接

本技能不要求选题落在教授的论文范围内：接着做不减分，不接着做也不直接扣分。因此“范围连接”默认权重 0，只作说明，不计入总分。

| 分 | 判据 |
|---|---|
| 2 | 研究室主线：教授近年论文或学生论文在做的问题 |
| 1 | 邻近：能借工具、数据或场景，但问题不是他们的主线 |
| 0 | 无关：教授只能提供通用指导 |

用户明确要把“导师能不能带”纳入比较时，把权重调到大于 0，并在表头写明。不能因为这一项低就自动淘汰候选；它影响的是录取策略，不是本技能判研究问题的标准。

判 2 还是 1 之前，先按[研究室的轴怎么判断](research-design.md#研究室的轴怎么判断)读教授的近年论文：同一句“相关问题”，在不同轴上要借的东西不一样。这一项仍按上表判，轴判断只作为判分输入，不自行启用或提高本项权重。

## 新证据进来时

先改受影响的评分项，再重算总分。不要只改总分不改依据。

评分保存在 `materials` 步骤；重新保存会让正文等下游步骤失效。选定方向后再补评分，先说明会影响哪些下游步骤，不要把它当成只读比较。

三种情况要整表重算：

- 权重变了。
- 评分项或判据变了。
- 证据截止时间变了，且新证据影响两个以上候选。

只改一个候选的一项时，其他候选的同一项也要用同一份新证据检查一遍；否则总分不可比。旧总分保留在记录里，标明“旧口径”，不要删掉。

## 保存

评分和候选一起保存到 `materials` 步骤的 `data.candidate_scores`，与 `candidates` 并列。保存三样东西：

- `weights`：实际启用的评分项权重；九项默认，启用“范围连接”时再加一项。如果用户调过，写实际使用的那一组，并标“按用户权重”，在旁边记一句用户原话和来源。
- `evidence_cutoff`：这一轮评分使用的证据截止日期。
- `items`：每项含 `id`、`question`、实际启用项的 `scores` 和 `evidence`、`total`、`gate`。`gate` 写 `pass`、`pending`、`soft_stop`、`hard_stop` 或 `merge`；另按 `gate` 写 `stop_reason`（`hard_stop` 时取 `novelty_zero`、`gap_zero`、`problem_invalid` 之一）或 `merged_into`（`merge` 时指向被并入的候选 `id`）。`hard_stop`、`pending` 和 `merge` 的候选不给总分。

结构可以按已有材料步骤调整，但不能省掉权重、证据截止时间和逐项依据。

## 四种常见打错

1. **把“查不到”当成“没人做”**。空白成因打 2 或 1 要有三篇最接近的工作和各自差在哪一步；打 1 还要按四位置写清变化，写不出按 0。
2. **把“落点写得清”当成“值得做”**。新意落点只判判定句套不套得出来；空白成因单独判这个空白该不该填。
3. **把“方法现成”当成“方法能落地”**。方法落地问的是数据从哪来、要多少、用什么工具、按什么顺序、怎么判断，不是“我会用这个工具”。
4. **把缺口数量当成新意**。合并两三个已承认的缺口，只是换一种论证结构，不改变证据要求。每个缺口仍要独立证据，空白成因仍按判据打分；三个各被承认一半的缺口凑不成一条新意。

评分只在需要给出选择建议时用。用户已经选定时，不要用分数推翻决定；新证据可能推翻时，先把证据和影响摆出来，再问用户。
