# 改稿、模板与恢复

## 采用用户修改稿

用户指定本轮采用的 Word 或 Markdown 后，先读当前正式状态，建立新工作版本，用 `import_revision` 保留交回原件并与其 `baseline_body` 比较。返回 AST 是待处理稿，不能直接写成已确认正文。

检查 `changes`、`comments`、`unsupported`：

- 插入、删除和其他未决修订先按用户已说明的接受、拒绝或指定修改处理；尚无决定时展示相关选择。不能默认全部接受或丢弃。
- 批注是反馈，结合上下文处理，不自动成为正文。
- 不能可靠读取的文本框、嵌入对象等，说明实际位置并保留原件；重要内容未处理前不发布省略后的成品。
- Markdown 普通内容差异同样需要判断影响。引用与新事实仍须核对材料。

比较的是用户意图及方案内容。纯措辞、排版或不改变结论的引用修正保留原确认；研究问题变化处理问题确认及受影响方案，核心方法或关键数据条件变化处理方案确认。用户已明确要求的实质修改直接执行并记录原意与来源；文件内意图不明的实质变化先展示改变及影响，只询问受影响部分。

两个相互冲突的版本且没有采用指示时，保留两份原件，展示差别后由用户选择，不按修改时间或文件名决定。导入时不覆盖旧版本；正式保存和导出都在新工作目录。

## 模板映射

先读正式表格本身及说明，不能因招生分析跳过空白表而忽略它。没有模板时，Word 与 Markdown 都从已保存 AST 导出。

可编辑 `.docx` 模板先读取其真实段落与表格位置，再为所需栏目制定 `mapping`。每项为：

```json
{
  "field": "研究方法",
  "target": {"table": 0, "row": 2, "column": 1},
  "body_blocks": [6, 7, 8]
}
```

这是索引字段示例，不代表任何真实学校模板。`target` 也可以是 `{paragraph: 5}`；所有模板索引和 AST 顶层 `body_blocks` 从 0 开始，必须由实际文档读出。不要在原模板上试写。映射需要覆盖采用正文，不能只把容易填写的部分导出而丢掉其他内容。

组件在模板副本中填写，保留未映射的学校固定文字与版式。`pandoc --reference-doc` 只提供样式，不等于填学校正文。PDF、旧 `.doc`、受保护文件或无法可靠填写的复杂模板，用同一栏目顺序和内容制作普通 Word 草稿：相应 `mapping.target` 设为空，明确标记需要转填，不声称已填原表。

导出后检查 Word 填写区域与 Markdown 的正文一致，不把学校固定标题、页眉、装饰文字当成正文差异。再查看全部 `page_images`：有没有缺页、溢出、文字不可读、栏目截断或篇幅不符。组件用独立 LibreOffice 配置生成预览；失败保留具体错误，不改用系统已打开的用户文档。

`review_revision` 的 `page_review` 只记录你实际看过当前页图的结果。正文或模板改变后，旧页图不再代表新稿，必须重新导出受影响内容并核对。两种格式及核对有效后才能提交。

## 版本与中断

本稿的 `研究计划状态.json` 是唯一入口，`current` 指向已提交稿，`works` 保存进行中的修订。每次操作消费返回的新 `state_version`；恢复前重新读磁盘，不用旧会话计数。

| 当前情况 | 继续方式 |
|---|---|
| 材料、候选、问题或中文方案保存后中断 | `resume_revision` 后采用仍有效数据，未保存的一步重新做；确认沿用真实记录。 |
| Word 成功、Markdown 失败，或反过来 | 旧提交仍有效；保留成功输出，正文与模板未变时只补失败格式，再核对提交。 |
| 输出内容不一致或页图核对失败 | 修复本轮问题，再导出和核对受影响结果，不切换当前稿。 |
| 完整目录改名，但状态尚未切换 | 只依 `pending_commit` 指定的修订恢复，重新核对成立才切换；不能扫描目录猜最新版。 |
| 已切换当前状态后中断 | 重报该提交版两个文件，不重复生成，也不退回旧版。 |
| 输入、模板、正文或用户选择变化 | 按 `next_steps` 重做依赖该变化的部分；无关材料与决定继续使用，实质变化按上面的确认规则处理。 |
| 别的一轮先保存或提交 | 保留本轮工作和新返回内容，报告冲突；重新读当前状态并确定采用版本，不用递增猜测覆盖后来决定。 |

正文变了就不能保留另一种格式的旧正文。已提交文件被用户修改时，先保留并导入修改原件，再开始新工作版本，不能通过恢复把修改擦掉。

## 同题申请另一学校

建立独立 `proposal_dir`、申请编号与用途；不要更改旧稿的绑定。读取新学校的实际表格、语言和篇幅，记录用户明确授权复用的文献和通用方案。复用决定指向来源稿与具体范围，不能把旧学校确认无条件复制为新学校全部确认。

在新稿保存复用材料及仍适用的研究问题/方案。已授权且没有改变的部分直接沿用；新要求引发的实质变化只确认受影响部分。新稿的正文、模板映射、进度、版本和交付各自保存，第一稿和其他教授状态保持原样。
